# Pinky Bread 2.0.0 Alpha 4

**Tag:** `v2.0.0-alpha.4`  
**Release date:** 2026-11-19  
**Release type:** Prerelease

## Highlights

- **Local-first live inference by default.** Docker Compose starts Ollama and uses `qwen2.5:3b` unless you choose another model.
- **Automatic model bootstrap.** `ollama-init` checks the persistent model store and pulls the configured model before API and worker startup.
- **Separate local service ports.** API/UI 8888, MCP 8060, Ollama 11434, PostgreSQL 5433, Valkey 6380 and SeaweedFS S3 8333.
- **Correct local DNS.** Host tools use loopback ports; containers use service DNS such as `ollama:11434` and `mcp:8090`.
- **Workspace navigation repair.** Sidebar navigation uses delegated click handling, explicit hit-area layering and cache-busted frontend assets.
- **Consolidated setup documentation.** README contains start-up steps, port mappings, host versus container endpoints, all environment variables, MCP configuration and troubleshooting.

## Start the release

```bash
git clone https://github.com/roime81/pinky-bread.git
cd pinky-bread
cp .env.example .env

# GitHub Codespaces only, when port forwarding needs a non-loopback bind:
# sed -i 's/^PB_BIND_ADDRESS=.*/PB_BIND_ADDRESS=0.0.0.0/' .env

docker compose config --quiet
docker compose up --build -d
docker compose ps
```

Open <http://127.0.0.1:8888>. In Codespaces, open port 8888 through the Ports panel.

The first startup downloads the selected Ollama model. Later starts reuse the named `ollama_data` volume.

## Upgrade notes

- Do not overwrite an existing `.env` with `.env.example`; preserve your tokens and customized settings.
- If an existing `.env` still has `MOCK_INFERENCE=true`, change it to `false` and recreate the stack with `docker compose up --build -d`.
- Inside containers use Docker DNS, not `localhost`: model URL `http://ollama:11434/v1`; MCP URL `http://mcp:8090/mcp`.
- The sample database and MCP credentials are for local development only. Keep all forwarded service ports private.

## Known boundaries

This is an Alpha prerelease. The included refund action remains simulated. Production authentication, tenant isolation, OIDC/JWT MCP identity, external tool approvals, production-grade PII/PHI detection and independently immutable audit storage are not implemented.
